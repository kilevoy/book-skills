# Скиллы из книг для AI-ассистентов (Claude Code, Antigravity, Codex)

Семь фундаментальных книг по продажам, управлению и переговорам, превращённых в инженерные скиллы. С ними языковая модель отвечает строго по правилам и фреймворкам авторов, а не усреднённо.

| Скилл | Книга | Для чего |
|---|---|---|
| `spin-selling` | «СПИН-продажи», Нил Рэкхем | большие B2B-сделки, выявление явных потребностей, извлекающие вопросы |
| `camp-negotiation` | «Сначала скажите „НЕТ“», Джим Кэмп | жесткие переговоры, избавление от нужды, эффект Коломбо, защита маржи |
| `voss-negotiation` | «Никаких компромиссов», Крис Восс и Тал Раз | психологический торг о цене, тактическая эмпатия, модель Аккермана |
| `goldratt-constraints` | «Цель», Элияху Голдратт и Джефф Кокс | поиск узкого места (TOC), связка сбыта с производством |
| `mom-test` | «Спроси маму», Роб Фитцпатрик | интервью с клиентами (CustDev), проверка рыночного спроса |
| `pishi-sokraschay` | «Пиши, сокращай», Максим Ильяхов и Людмила Сарычева | строгий инфостиль деловой переписки и коммерческих предложений |
| `atomic-habits` | «Атомные привычки», Джеймс Клир | преодоление саботажа, стандарты CRM и регулярность |

## Установка

Antigravity:
```bash
cp -R book-skills/skills/* ~/.gemini/config/skills/
```

Claude Code:
```bash
git clone https://github.com/kilevoy/book-skills.git
cp -R book-skills/skills/* ~/.claude/skills/
```

Codex / Cross-agent:
```bash
git clone https://github.com/kilevoy/book-skills.git
mkdir -p ~/.agents/skills
cp -R book-skills/skills/* ~/.agents/skills/
```

После копирования перезапусти Claude Code или Codex. Скилл подключается сам,
когда задача подходит под его описание. В Claude Code его можно вызвать и по
имени, например `/pishi-sokraschay`.

## Что внутри скилла

- `SKILL.md`: главные методики книги и указатель по темам
- `chapters/`: конспект каждой главы отдельным файлом, модель читает только нужную
- `glossary.md`: термины книги
- `patterns.md`: приёмы и техники
- `cheatsheet.md`: шпаргалка с правилами

Скиллы собраны инструментом [book-to-skill](https://github.com/virgiliojr94/book-to-skill).

Это конспекты для работы, а не текст книг. Сами книги стоит прочитать целиком.
