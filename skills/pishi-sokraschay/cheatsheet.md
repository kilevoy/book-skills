# Шпаргалка решений

## Если X, делай Y
| Если в тексте… | Делай | Потому что |
|---|---|---|
| оценка («качественный», «быстрый») | факт или сценарий | собственный вывод читателя прочнее чужой оценки (гл. 5) |
| усилитель («очень», «максимально», «настоящий») | удали, дай факт | отнимает силу у главного слова (гл. 5) |
| «как известно», «не секрет» | удали или назови источник | известное писать незачем, неизвестное как известное неправда (гл. 4) |
| «во-первых, во-вторых» | абзацы | цифры только для шагов и пунктов со ссылками (гл. 4) |
| «в наши дни», «сегодня» | удали, докажи данными | настоящее время по умолчанию (гл. 6) |
| «осуществлять / оказывать + существительное» | один глагол | действие спрятано (гл. 9) |
| страдательный залог | действительный, с деятелем | маскирует ответственного; кроме состояния («дом сдан») (гл. 9) |
| «более», «около», «от N рублей» | точное или округлённое число; что стоит N | читатель запоминает только число; «от» манипуляция (гл. 10) |
| «входим в топ-10» | польза от размера | рейтинг читателю не нужен (гл. 10) |
| «всё больше внимания общественности…» | статистика, источник или честное «я» | брехня подходит к любой теме (гл. 11) |
| эвфемизм в плохой новости | прямо + план | скрытая проблема вырастает (гл. 8) |
| просят «сгладить» | выясни, чьи интересы | кто-то не понимает задачу текста (гл. 12) |
| тяжёлое предложение без мусора | посчитай мысли, разбей | одна мысль на предложение (гл. 13) |
| много запятых, «сказал, что» | раздели, упрости подчинение | запятая маркер узла (гл. 15) |
| ряд синонимов | одно точное слово или факт | читатель их не различает (гл. 16) |
| абзац о нескольких темах | раздели | одна тема на абзац (гл. 17) |
| непонятно, о чём текст | сформулируй «А» и «Б» | цель задаёт состав (гл. 18) |
| креативный заголовок | тема или польза | заголовок отвечает «о чём» (гл. 20) |
| голая характеристика | перевод в опыт и пользу | факт должен быть в мире читателя (гл. 23) |
| звучит механически | перепиши на слух | форма служит смыслу (гл. 24) |
| регалии, громкие клиенты | что делал и какая польза | из регалий пользы не следует (гл. 28) |

## Пороги
- Новых мыслей в предложении: 1 для новичка, 2 при тесной связи, до 3 у профессионалов; больше опасно (гл. 13).
- Абзац: одна тема (гл. 17).
- Вслух не хватило воздуха → длинно; сбилась интонация → сложно (гл. 4, 14).
- Округляй до нужной читателю точности; дату ставь, если число меняется (гл. 10).
- «Главред»: хорошая оценка информационного текста около 7 баллов (гл. 31).

## Выбор начала
- Письмо, резюме, новость, инструкция, КП → главная полезная мысль первой.
- Рецензия, колонка → интрига или история, но не в каждом абзаце.
- Вступление: обучающая статья → погружение или актуализация; развлекательная → интерес или доверие.

## Заголовок
- Читатель ищет → его словами поиска, без креатива.
- Читатель не искал → явная польза темы.
- Тест: заголовок отдельно от статьи, с твоей подписью, не вводит в заблуждение.

## Признаки слабого текста
- Подставь любую отрасль вместо ключевых слов, ничего не изменилось → пустословие (гл. 6, 27).
- Запахло рекламой, официозом, газетой → штампы (гл. 6).
- Подпись «Администрация» → нет ответственного (гл. 6).
- Огромное неровное число без источника → вредительский факт (гл. 23).
- Спор о словах → в тексте мало смысла (гл. 31).
