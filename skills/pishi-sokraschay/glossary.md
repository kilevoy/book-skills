# Глоссарий

Ссылка «гл. N» указывает на файл `chapters/chNN-*.md`.

**Абзац**: смысловой блок на одну тему (гл. 17)
**Абстракция**: понятие, которого нет в материальном мире (качество, сервис) (гл. 22)
**Брехня**: расплывчатая формулировка, формально не ложь, но и не правда; позволяет не предъявлять факты (гл. 11)
**Вводные конструкции**: слова, не связанные грамматически с предложением («безусловно», «как известно», «во-первых») (гл. 4)
**Видимость вежливости**: формальная, лакейская вежливость в словах без заботы на деле (гл. 4)
**Главред**: сервис авторов, подсвечивающий стоп-слова и проблемы синтаксиса (гл. 3, 31)
**Графомания**: текст, написанный для пишущего, а не для читателя (гл. 2)
**Демонстрация**: показ продукта в действии; сильнее текста и иллюстраций (гл. 25)
**Дидактика**: дисциплина о принципах обучения (гл. 21)
**Заказчик и кадровик**: участники найма; кадровик фильтрует отклики по требованиям для заказчика (гл. 29)
**Задачи текста**: смысловые ходы, ведущие к цели («какой дорогой») (гл. 18)
**Задачи читателя**: проблема, которую читатель решает с помощью текста (гл. 2)
**Заумь (заумное)**: сложные слова, которыми пользуются, чтобы казаться умнее (гл. 7)
**Информативность**: число новых мыслей в предложении; норма для новичка: одна (гл. 13)
**Информационный стиль (инфостиль)**: редакторская дисциплина: сложное просто, главное выделено, выводы делает читатель (гл. 1)
**Канцеляризм**: оборот из речи бюрократов («осуществляется», «в целях», «посредством») (гл. 6)
**Кикер**: интригующий первый абзац статьи (гл. 17)
**Конкретика**: то, что воспринимается органами чувств и легко представить (гл. 22)
**Культ слов**: вера в силу слов в отрыве от смысла (гл. 1, 31)
**Ложное чувство проделанной работы**: ощущение, что оценкой или усилителем всё сказано (гл. 5, 7)
**Модуль**: самодостаточная часть статьи с подзаголовком: введение, основная часть, вывод (гл. 19)
**Неопределённое**: «более», «около», «от», «некоторые», «различные», рейтинги без пользы (гл. 10)
**Обобщение**: слово-категория с числом перед перечнем («три инструмента: …») (гл. 13)
**Объяснение по цепочке**: ввод промежуточных понятий перед целевым (гл. 13, 21)
**Однородные члены, близкие по смыслу**: ряд синонимов, которые читатель не различает; сокращаются (гл. 16)
**Ограничения**: честно названные случаи, когда вы или продукт не поможете (гл. 26, 27)
**Отглагольное существительное**: действие, спрятанное в существительное («продажа», «обеспечение») (гл. 9)
**Оценка**: субъективная характеристика вместо факта («качественный», «вкусный») (гл. 5)
**Паразиты времени**: «в наши дни», «в современном мире», «сегодня» без противопоставления (гл. 6)
**Парцелляция**: дробление предложения точками на неполные фразы (гл. 14)
**Передёргивание**: заголовок, искажающий суть через вырванный из контекста факт (гл. 20)
**Поток сознания**: изложение по ассоциациям (гл. 17)
**Проверка чёрным маркером**: замазать названия продуктов и услуг, затем проверить, не подходит ли текст любой компании (гл. 27)
**Пять правил рассказа о продукте**: простые слова, польза для клиента, детали и сценарии, доказательства, уважение и забота (гл. 26)
**Регалии**: дипломы, звания, награды, членство; без объяснения пользы бесполезны (гл. 28)
**Сглаженные углы**: витиеватые фразы, прикрывающие неприятную правду (гл. 6, 8)
**Сильное подлежащее**: тот, кто может действовать (человек, фирма); слабое: абстракция или отглагольное (гл. 14)
**Сильное сказуемое**: глагол действия; слабое: глагол состояния («являться», «находиться») (гл. 14)
**Стоп-слова**: слова, которые удаляются без потери смысла; восемь групп (гл. 3)
**Страдательный залог**: «действие наизнанку»; маскирует деятеля (гл. 9)
**Сценарий**: ситуация, в которой продукт или услуга полезны (гл. 5, 26, 27)
**Тонкости**: детали, известные только профессионалу; доказывают экспертность (гл. 26, 27)
**Усилитель**: оценка поверх оценки («очень», «максимально», «абсолютно») (гл. 5)
**Факт в мире читателя**: число, сопоставленное с опытом читателя (60 м = 17-этажный дом) (гл. 23)
**Формализм**: соблюдение формального порядка в ущерб пользе (гл. 6)
**Цель текста**: что должно измениться в голове читателя; путь из «А» в «Б» (гл. 18)
**Штамп**: затёртое устойчивое сочетание, смысл которого неясен или выражается одним словом (гл. 6)
**Эвфемизм**: безобидный синоним вместо неприятного слова (гл. 8)
**Эффект соседства чисел**: стоящие рядом числа провоцируют невольные вычисления (гл. 23)
