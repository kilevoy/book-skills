# Рабочие шаблоны по книге

## 1. Собрать Commercial Teaching pitch
**Когда:** нужно открыть разговор новой перспективой, а не каталогом продукта.  
**Шаги:**
1. Определи реальную сильную способность поставщика.
2. Найди сегмент и бизнес-проблему, для которых эта способность значима.
3. Сформулируй инсайт, меняющий оценку ситуации.
4. Подтверди его данными и ценой бездействия.
5. Покажи человеческое/операционное последствие.
6. Объясни новый способ действовать.
7. Только затем покажи, как решение поставщика это обеспечивает.
**Проверка:** фактологичность, клиентская значимость, способность поставщика исполнить, следующий шаг.

## 2. Подстроить сообщение к stakeholder'у
**Когда:** в покупке участвуют несколько функций и уровней.
**Матрица:** отрасль → компания → роль → человек. Для каждого участника зафиксируй желаемый результат, метрику, риск, аргумент и нужное доказательство. Проверяй предположения в разговоре; не читай карточку как скрипт.

## 3. Подготовить переговоры
**До встречи:** целевой результат; сильные/слабые стороны; что нужно узнать; вероятные возражения; план уступок; цена каждой уступки для продавца и её ценность для клиента.
**В разговоре:** Acknowledge and Defer → Deepen and Broaden → Explore and Compare → Concede According to Plan. Уступай только при понятном встречном шаге или изменении условий; не начинай с автоматической скидки.

## 4. Провести PAUSE-коучинг
Подготовься к одной наблюдаемой ситуации → обозначь развивающую цель и поддержи отношения → сравни ожидаемое и наблюдавшееся поведение → согласуй конкретное изменение → договорись о практике и последующем закреплении. Отделяй коучинг поведения от разбора одной только квоты.

## 5. Проверить готовность организации к внедрению
Проверь наличие: руководительского спонсора; правдивых insight-led сообщений; подготовки продавцов; обученных frontline managers; инструментов под stakeholder'ов; практики/коучинга после курса; показателей adoption. Пилот оценивай по барьерам, различиям между группами и применению на реальных сделках, а не только по удовлетворённости тренингом.

**Анти-паттерны:** generic pitch; «мы инновационные» без доказательств; инсайт без связи с реальным преимуществом; tailoring только по должности; агрессия вместо assertive empathy; скидка без понимания причины; считать каждого top performer Challenger; единичный тренинг вместо внедрения.
